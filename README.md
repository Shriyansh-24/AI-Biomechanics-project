# AI-Biomechanics-project
This project bridges the gap between High-Performance Sports and Artificial Intelligence. As a national-level Track athlete, I am developing a tool that uses Computer Vision to analyze joint kinematics. The goal is to identify "at-risk" movement patterns—such as excessive knee positions or improper hip-shoulder separation

# 1. The Problem
As a national athlete in Track and Field, I noticed a high rate of ACL, Hamstring, Hip injuries. I am using Computer Vision to analyze joint angles to identify 'at-risk' movement patterns

Language: Python
Libraries: OpenCV (Video processing), MediaPipe (Pose Estimation), NumPy (Mathematical calculations).
